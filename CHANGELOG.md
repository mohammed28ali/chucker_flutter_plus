# Changelog

## 1.0.5

- Added Linux, macOS, and Windows desktop support and example runner setup.
- Added image previews and video response details to the media tab.
- Bounded retained media previews by the configured body size limit.

## 1.0.4

- Improved package analysis compatibility and documented the 1.0.3 release.

## 1.0.3

- Improved package metadata and compatibility across Flutter platforms.
- Added Chopper and `package:http` network logging adapters.

## 1.0.0

- Added the in-app HTTP inspector with bounded request history, banners, and optional system notifications.
- Added request capture for Dio and `package:http`.
- Added the shared `NetworkLogger` with Dio, Chopper, and HTTP adapters.
- Added configurable redaction, retention, filtering, export, and request detail tools.

## 0.1.0

- Added Dio and `package:http` adapters for capturing requests and responses.
- Added the in-app inspector, request filtering, body sizes, copy, cURL, and sharing.
- Added configurable in-app banners and system notification delivery.
- Added bounded local history, retention, and sensitive-header redaction.
- Added the shared `NetworkLogger` with Dio, Chopper, and HTTP adapters.
